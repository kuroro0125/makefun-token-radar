How the board is priced

Protocols whose token already trades set the rate: for each category the board takes the median market-cap-to-TVL ratio of its tokenised members. A pre-token protocol is priced at its own TVL times its category rate, adjusted for its seven-day TVL growth, for how long it has run with no token, and for how many chains it operates on. The board's universe is plausible launches only: wrapped, staked and bridged products of tokens that already trade, canonical bridges, exchange entries and superseded old versions are set aside before ranking, the same line the snapshot's watchlist draws. The figure is the board's own claim about a hypothetical launch, not a prediction that a token is coming. Data: a sealed DefiLlama snapshot; the page runs entirely from local files.
